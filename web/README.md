# Sitio Web

## Estructura de Carpetas

```

GAMY-project                    -> Repositorio Principal
└─ web                          -> Carpeta para la pagina web 
   ├─ imagenes                  -> Carpeta para las imagenes usadas en la web  
   │  ├─ background-black.png   -> Imagen de prueba 
   │  ├─ godot.jpg              -> Imagen banner para la web 
   │  ├─ pfp_prueba.jpeg        -> Imagen de miembro del equipo
   │  ├─ pfp_prueba2.png        -> Imagen de miembro del equipo
   │  ├─ pfp_prueba3.png        -> Imagen de miembro del equipo
   │  ├─ pfp_prueba4.jpg        -> Imagen de miembro del equipo
   │  └─ screen-juego.png       -> Imagen ilustrativa del juego
   ├─ index.html                -> Pagina Web
   ├─ README.md                 -> Archivo MarkDown para mostrar informacion sobre la carpeta 
   ├─ script                    -> Carpeta para archivos JS (JavaScript)
   │  └─ script.js              -> Archivo JavaScript
   ├─ styles.css                -> Estilos de la pagina web
   └─ videos                    -> Carpeta para videos o gifs
      └─ Multiplataformero-Gameplay-ezgif.com-video-to-gif-converter.gif  -> Gif del juego
```
